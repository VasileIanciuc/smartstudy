# SmartStudy Working Responsive Demo

This is a frontend demo version of SmartStudy. It works without backend/database so it is good for demo screenshots.

## Run in Visual Studio Code

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Login

Use any email and any password, then press Login.

## Working buttons

- Get Started
- Login / Sign up
- Bottom navigation: Home, Tasks, Focus, Analytics
- Calendar shortcut
- AI Planner shortcut
- Add New Task
- Save Task
- Complete task
- Delete task
- Start / Pause / Reset focus timer
- Generate / Regenerate study plan
